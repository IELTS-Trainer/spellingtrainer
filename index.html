⌨️ Typing Climb

Choose a level and practise spelling as you climb.

Level 1 · Topic Practice

  1. Choose a topic, then type each displayed word.
  2. If you misspell a word, practise its syllables. Then type the complete word correctly to continue.
  3. Work through the words in your selected topic. There is no mistake limit.
  4. Misspelled words are added to Last Mistakes for later practice.

Level 2 · Random Mix

  1. Listen to words selected at random from all topics and type each one.
  2. If you make a mistake, syllable practice opens for that word.
  3. Misspelled words are added to Last Mistakes. The game ends when you reach the mistake limit set in Settings (10 by default).
